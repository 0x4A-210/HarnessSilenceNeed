# 执行期间的只读诊断

大型项目分析期间，用 py-spy 从进程外读取调用栈，确认时间消耗的位置。工具仅安装在运行容器的 `/tmp/fi-profiler`，或复制到 `/tmp/fi-profiler-bin`；未安装到 FI 的 Python 导入路径，也未修改被分析进程的源码、函数或数据结构。它不参与构建、分析、判断或结果汇总，复跑不需要该工具。

采样显示 PostgreSQL 和 binutils 的官方 C/C++ 前端正在计算函数调用深度，通过 `_find_source_with_func_def` / `get_function_node` 查找定义。采样中的查找名包括宏形式的 `CHR`、`SHI_NFP_IREG_ISLAND`。当前官方提交中该查找会遍历函数列表；这解释了大型源码树中显著的计算开销，但单次采样不能推导精确剩余耗时。

原始栈快照和安装版本日志保留在本目录。没有为加速而添加过滤规则、缓存补丁、修改官方阈值或跳过原生分析。
